#Ethiopian Orthodox Library

A simple web library for Ethiopian Orthodox Tewahedo spiritual and
liturgical content.

The project starts with **Serate Kidase** audio and will later include
other sections such as:

- ሥርዓተ ቅዳሴ — Kidase
- ማኅሌት — Mahlet
- ሰዓታት — Seatat

Features

- Kidase audio recordings
- Play and pause audio
- Spiritual images
- Mobile-friendly design
- More collections coming soon

 Built With

- HTML
- CSS
- JavaScript

No framework is used.

Project Goal

The goal is to make Ethiopian Orthodox spiritual content easy to
access through a simple and modern website.

Future Plans

More audio, images, and spiritual collections will be added over time.
